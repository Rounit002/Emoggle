# OpenMoji subset

This directory contains the color SVGs used by Emoggle's emoji prompts and
gameplay surfaces. They are copied from OpenMoji 17.0.0.

All emoji artwork is designed by OpenMoji, the open-source emoji and icon
project, and is licensed under CC BY-SA 4.0. See `LICENSE.txt` in this
directory and https://openmoji.org/.

Only the SVGs currently used by Emoggle are bundled so the application does
not ship the complete OpenMoji package.
